Selected reference skills from [calesthio/generative-media-skills](https://github.com/calesthio/generative-media-skills)
(MIT — see `LICENSE`), copied 2026-09-10. These are production-craft knowledge
files (provider-independent), not executable code — read them when planning
scenes, compositing, character continuity, or sound.

Copied selectively, not the full 153-skill repo:

- `character-design-continuity` — locked "character anchor" prompting for consistency across generations
- `vfx-compositing` — shot integration: contact shadows, color/light matching
- `2d-character-rig-animation` — reusable rig part decomposition, visemes, cycles
- `storyboard-previsualization` — script-to-scene breakdown
- `sound-design-foley` — ambient/effect sound direction (not used yet)
